# PhraseSyncMaster
PhraseSync Master is a (WIP) real-time MIDI plugin for synchronizing, filtering, arpeggiating, and automating complex MIDI data streams while preserving the expressiveness and cleanliness of the signal.
Thanks to Rua Haszard for his "SyncPhrase Plugins" here at https://github.com/haszari/PhraseSyncPlugins and to Yves Parès (aka Ywen) for his "Arpligner" plugin here at https://github.com/YPares/arpligner . 
This work started with a refactoring of R. Haszard's plugins  by chaining them in a given sequence and into a single interface, integrating them with Y. Parès's arpeggiator.
